# بوابة التواصل الإداري الداخلي

تطبيق **Node.js / Express** (قوالب EJS) محوَّل من 4 واجهات HTML ثابتة، وأصبح الآن **واجهة واحدة موحّدة ومترابطة** مع **حسابات مستخدمين**: عند إنشاء الحساب يختار المستخدم الحسابات التي يمكنه التواصل معها، ولا يرى أو يتصل بغيرها.

## التشغيل

```bash
npm install
cp .env.example .env      # ثم عدّل SESSION_SECRET
npm start                  # أو: npm run dev
```
افتح `http://localhost:3000` (لا تفتح ملفات `.ejs` مباشرة في المتصفح).

## المتغيرات (`.env`)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | المنفذ | `3000` |
| `NODE_ENV` | `development` / `production` | `development` |
| `AGENCY_NAME` | اسم الجهة في الواجهات | `مصلحة الضرائب` |
| `SESSION_SECRET` | سر توقيع الجلسة (**إجباري في production**) | مفتاح تطوير مؤقت |
| `COOKIE_SECURE` | `true` عند التشغيل عبر HTTPS فقط | `false` |

## الصفحات

| المسار | الوصف | يتطلب دخولًا |
|---|---|---|
| `/login` | تسجيل الدخول | لا |
| `/register` | إنشاء حساب (زر «إنشاء حساب جديد» في **دليل الموظفين**؛ يعمل أيضًا لمن لا يملك حسابًا) | لا |
| `/` | الرئيسية (ملخص + المتصلون الآن) | نعم |
| `/directory` | دليل الموظفين (الحسابات المتاحة لك فقط) + زر إنشاء حساب | نعم |
| `/calls` | المكالمات الأخيرة (مع الحسابات المتاحة فقط) | نعم |
| `/call/active?contact=ID` | مكالمة صوتية (معاينة) — **403** لأي حساب غير متاح | نعم |
| `/notifications` | الإشعارات | نعم |
| `/settings` | بيانات الحساب + تعديل الحسابات المتاحة للتواصل | نعم |

واجهة REST للقراءة (تتطلب دخولًا): `GET /api/calls` · `GET /api/contacts` · `GET /api/notifications` — كلها مفلترة حسب صلاحيات المستخدم.

## الهيكل الإداري والصلاحيات

- الهيكل في **`data/org.json`** (77 وحدة: رئيس المصلحة ← المكاتب ← نائب الرئيس ← الإدارات العامة وأقسامها ← 27 إدارة ضرائب بالمناطق). لتعديله عدّل الملف فقط (لكل وحدة `id` ثابت؛ أضف وحدات جديدة بمعرّفات جديدة ولا تغيّر القديمة).
- عند إنشاء حساب يختار صاحبه **موقعه في الهيكل** (إدارة/مكتب/قسم) — مستقل تمامًا عن مسماه الوظيفي. بناءً على الموقع تظهر له الحسابات التالية فقط ليختار منها:
  1. **مديره المباشر**: الحسابات الموجودة في الوحدة الأعلى مباشرة.
  2. **نفس المستوى**: زملاء وحدته + الوحدات الشقيقة تحت نفس المدير.
  3. **من يندرج أسفله**: الحسابات في كل الوحدات التابعة له (بأي عمق).
- **الفرض من الخادم**: الدليل والمكالمات وواجهة API وصفحة المكالمة تعرض/تسمح فقط بما اختاره المستخدم **وبما يسمح به الهيكل حاليًا**؛ تعديل الرابط أو إرسال معرّف غير مسموح لا يتجاوزها.
- الحسابات التي تُنشأ لاحقًا تظهر تلقائيًا في القائمة المناسبة، ويختارها المستخدم من **الإعدادات** (لا تُمنح تلقائيًا).
- عقد «المجموعات» في الهيكل (الإدارات العامة، الإدارات بالمناطق) تصنيفات عرض فقط: لا يمكن اختيارها كموقع، ولا تُحسب مديرًا.

## الأمان

- كلمات المرور مُجزّأة بـ `scrypt` مع salt لكل مستخدم (لا تُخزَّن نصًا).
- جلسة موقّعة (`cookie-session`): `httpOnly` + `sameSite=lax`.
- رمز CSRF لكل نموذج POST، وحد لمحاولات الدخول/التسجيل، ومنع التحويل الخارجي بعد الدخول.
- `helmet` مع CSP مقيّدة بمصادر التصميم فقط.

## البنية

```
server.js
src/{config,routes,controllers,services,middleware}
views/{partials,pages}      # layout-start/end + sidebar موحّدة لكل الصفحات
public/{css,js}
```

## ملاحظات مهمة

1. **التخزين ملفات JSON** (`data/users.json`) — مناسب للمعاينة/التطوير. للإنتاج الفعلي استبدل `dataService` بقاعدة بيانات.
2. **افتراضات في تفسير الهيكل** (قابلة للتعديل في `org.json`): الإدارات العامة (الفنية) والإدارات بالمناطق تتبع رئيس المصلحة مباشرة؛ مكتب الشؤون القانونية وقسم الشؤون الإدارية والمكاتب المذكورة بعد «نائب رئيس المصلحة» تتبعه؛ «قسم الإحصاء ومطابقة الحسابات» قسم واحد. حقل `kitchen` («مطبخ 1/2» أو مطبخ الإدارة) محفوظ كما ورد ولا يؤثر على الصلاحيات.
3. **مواقع الموظفين الثمانية الأساسيين** وُضعت بما يقارب مسمياتهم القديمة (مثل: أحمد وسارة ← قسم العلاقات العامة، خالد ← قسم شؤون الموظفين، نادية ← قسم الشبكات والدعم الفني، محمود ← إدارة ضرائب مصراتة، ليلى ← إدارة ضرائب طرابلس، مريم ← مكتب المتابعة، يوسف ← مكتب المراجعة الداخلية). عدّلها في `data/accounts.json` (`unitId`).
4. **التسجيل مفتوح** لأي زائر يصل للموقع (وقائمة الحسابات المقترحة تظهر قبل الدخول). للاستخدام الفعلي يُنصح بتقييده (دعوة/موافقة مسؤول).
5. المكالمات والرسائل **معاينة فقط**؛ سجل المكالمات بيانات تجريبية تُعرض للحسابات المسموح بها.
6. حُذفت سكربتات `/_sdk/*` الخاصة بأداة التصدير الأصلية، وعُطّل `upgrade-insecure-requests` في CSP لأنه كان يُفقد الصفحة تنسيقها في بعض المتصفحات على `http://localhost`.
